# MagangYukApp

Android App untuk mengelola program magang dari pencarian, pendaftaran sampai penilaian, dibuat dengan Kotlin di Android Studio. Mendukung beberapa role dalam satu aplikasi.

## Role & Fitur
1. Mahasiswa
- Cari dan lamar lowongan magang
- Pantau status lamaran
- Lihat nilai dan feedback

2. Perusahaan (Pembimbing Lapangan)
- Posting lowongan magang
- Seleksi pelamar
- Beri penilaian magang

3. Kampus (Dosen Pembimbing)
- Pantau progres mahasiswa bimbingan
- Beri penilaian dan feedback

## Tech Stack
- Kotlin
